# 0014 · Lastro de cada número conferido antes de gravar

Antes de gravar uma resposta ou montar um PDF, o código confere que cada número do texto aparece no resultado da consulta; se algum não aparece, a resposta vira "não consegui". Assim, o número inventado é barrado em tempo real, com a meta de 0 número sem lastro entregue.

Descartadas: números preenchidos pelo código a partir de marcadores escritos pelo modelo; garantia só pela avaliação.
Custo aceito: um número derivado, como uma variação percentual, precisa vir pronto da consulta, senão a resposta é barrada.
