# 0004 · Plataforma gerenciada (PaaS) com banco gerenciado

O sistema roda numa plataforma gerenciada, com Postgres e Redis gerenciados, em vez do servidor único sugerido pelo brief. HTTPS, implantação e volta automática de versão vêm prontos, com menos operação. Qual PaaS está a definir.

Descartadas: servidor único (VPS) de 2 GB com contêineres, sugerido pelo brief; servidor único maior.
Custo aceito: várias peças pagas separadamente, e o custo cresce com cada contêiner; a gestão de configuração fica presa à plataforma.
